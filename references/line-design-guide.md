# 线条设计与核心线色：69张高清参考

本规范将原作观察、像素取色和新头像的执行规则分开。完整逐图记录在 [line-library.json](line-library.json)，编号仍为 HD-001–070，HD-051 缺号。缩略图与主线色卡在 `assets/line-library/`，来源图及作者信息沿用已有素材说明。

## 1. 如何提取

逐张查看高清成品，先判断线条所处的角色，再在原 PNG 的实色线内取样。每张保存原图路径、SHA-256、主线 HEX、取样坐标、画法分类、四类线条观察及确有必要的辅助线色。取样坐标以左上角为原点、从0开始，单位为原图像素。

不能把像素最多的颜色当主线：那可能是背景或衣服。不能只挑最暗的颜色：那可能是头发填充、张嘴负形或局部饰品。主线以脸缘、头肩轮廓及眉眼短线的连续使用关系判断；一种颜色同时出现在填面与线条中时，记录它作为线条的取样点。

HEX 是成品栅格中的精确 RGB，不声称取得作者源工程色板。抗锯齿边缘、相邻像素微差和缩略图压缩色不作为新颜色随意扩充；低置信的角色判断要保留说明。画法分类是本 Skill 的归纳，同一原作可能含多种手法，记录一个主类并在备注补充。

## 2. 按用途绘制

| 线条用途 | 处理方法 | 颜色来源 |
|---|---|---|
| 人物外轮廓 | 发型、脸缘、颈肩以大弧和必要折点连接；遮挡处断线，不重复描边 | `line_plan.primary_hex` |
| 五官、耳内 | 眉眼实心概括，鼻口短线；保持个体间距与神态 | 同一核心线色；统一实心眼规则优先 |
| 发型内部 | 整片发面；全头默认0–2条必要结构线，最多3条，只说明分缝、刘海遮挡和前后层 | 同一核心线色；渐变跨大面，不增分束线 |
| 衣饰结构 | 领口、肩袖、主要折叠和真实配饰接触位置 | 同一核心线色，线可略轻 |
| 服装纹理 | 默认省略，必要时细疏、顺衣片、受遮挡裁切 | 同色细线，不能另捏新主线色 |
| 装饰亮线、偏色短边 | 本版仅存档，不绘制；尚无启用参数 | 所选原图 `secondary_colors` 中注明角色的采样色 |

不为脸侧暗面、腮红或每个渐变边界额外描边。深发、暗面、主线和背景即便色相相近，也各有角色，不能混用取样依据。线宽比仅为新图建议：外轮廓为1，五官约0.75–1，发内及衣饰约0.65–0.9；按头像显示效果调整，不冒充作者笔刷设置，线宽建议不改变本次输出尺寸。

### 发型减法规则

这是用户对新头像的进一步简化要求，执行规则保存于 `line-library.json.role_rules.hair`（`silhouette-first-v3`），不是对69张原作的线数统计或作者笔刷参数。原图逐张观察档案保持原样。

- 先完成一整片可辨认的发型剪影，再按分缝、刘海遮挡与前后层合并成必要大面；能用一片表达时不拆块，发面内部应有大片留白。保留长短、体积、发际线、分缝、刘海和脸侧遮挡，不靠增加发丝保证辨识。
- 全头发内结构线默认0–2条，最多3条；无助分缝或遮挡识别的线删除，不为凑数加线。这个预算覆盖全部发块，不能每块各画3条。每条内部边线均计入，逐缕封闭的两侧分别计数；发型外轮廓、脸发交界及真实配饰轮廓不计入，但不能借此把发面拆成密集尖束。
- 优先删头顶树枝形/扇形放射线与重复拱线、侧后发平行外缘的重复长线及孤立短线。分叉逐支计数；发内分层与贴外缘的第二道线也计入总预算，不能以“轮廓”名义保留。先不画内部纹理，仅在分缝或遮挡无法辨认时补线。
- 保留原有卷度。顺直或微弯发顺势垂落，只在原照弯曲处概括转折；不能用连续大S卷代替碎发。真正卷发保留蓬松剪影和外缘少数主要起伏，不逐卷描边，不把头顶画成均匀重复的波瓣。
- 短发收拢锯齿碎边，长发合并相邻发尾；辫发、盘发保留位置、粗细与总体走势，只在确需说明编织或交叠处留线，不逐节重复。光头或无可见头发时不补造发块。
- 层次靠大面遮挡、必要暗面及整片内部的连续渐变表达；不为渐变新画分束边线、密集平行线或分条高光。渐变边界不描线。
- fast/review、预览/高清均从同一库读取；旧brief、图2或旧预览的密集发丝不继承，已认可构图、人物关系与配色继续保留。高清提高边缘清晰度，不增加线条数量；仅本次用户明确要求更细致发型时调整预算。

实际看图时核对是否仍有重复波瓣、逐束封闭或人为加卷；线数是绘制目标，提示词不等于模型已严格执行。普通fast在原有一次三图对照中检查，不追加生图或单独分析流程。

## 3. 四个主类与一种可叠加手法

| 分类 | 用线特征 | 新图采用条件 |
|---|---|---|
| `rounded-monoline` 圆润常规单线 | 平顺大弧、相对稳定线宽、少量折点 | 默认 flat / gradient |
| `bold-graphic` 粗线图形 | 较重轮廓与实心形，减少内部线 | bold / cartoon |
| `fine-structured` 细线结构 | 轮廓清楚，服装结构和纹理更轻 | texture，照片衣物支持时 |
| `open-duotone` 留白彩色单线 | 单一核心色、负形留白、有意断线 | duotone；眼睛仍用统一符号 |
| `offset-accent` 局部强调边线 | 归纳原图的局部亮线与并行边；本版只用同主线色短段强调 | 可选组合手法；辅助色仅存档，不绘制 |

本批主类分布为圆润单线40张、粗线图形17张、细线结构7张、留白彩色单线5张。`offset-accent`不独占原图主类；它是从其中13张的局部亮线或亮边归纳的可叠加手法，证据编号见库中`technique_reference_ids`。项链、耳饰、服装排线另外按其真实角色记录，不一概当作装饰亮边。

画法分类决定线条组织，不替换人物脸型、发型、衣型和动作。当前用户要求的发型简化、实心眼、纯色背景和人物局部渐变始终有效；原图中的写实眼部、背景渐变等不迁移。

## 4. 生图时如何读取

执行器先选择已入库完整原作，再从同一原作读取主线。所有单图和四图均按[source-colors.md](source-colors.md)整套绑定肤色、背景、发衣、主线与渐变；不独立抽色。确认高清后冻结完整来源，线条分类只影响画法，不改变角色颜色。

单图用 `--variants 1 --colorway-reference 55` 选择完整原作。兼容的 `--line-reference` 也必须选择整套已收录原作，不能只借线色。`--line-family` 仅改变线条组织；造型参考HD-025不替换照片人物。

```bash
python3 "<skill-dir>/scripts/run_avatar.py" \
  --photo "/人物照片.jpg" \
  --feature "可见脸型与下颌" \
  --feature "发型大剪影" \
  --feature "眉眼关系" \
  --expression "照片表情视线" --pose "照片头肩方向" \
  --variants 1 --colorway-reference 55 --line-family rounded-monoline
```

新请求通过 `--colorway-reference` 选择完整原作；兼容 `--line-reference` 时也选择该原作整套配色，不能只借线色。多个显式选择器指向不同原作时停止。旧 brief 中的 `color_roles.outline` 和其他独立角色字段统一迁移到完整方案并记录原因，原历史文件保留。明确要求局部改色时说明与同源规则冲突，不通过旧字段覆盖来源。

背景与主线一次取自同一原作，不能从背景池单独换色；需要调整时另选整套完整方案。所有提示词均带精确 HEX 和四部位用线要求；模型可能近似执行，提示词固定不等于像素已经严格一致。不得把模型输出的偏色说成精确通过，也不在普通 fast 中追加收费重画。

## 5. 复核与维护

`scripts/analyze_lines.py` 可离线核对69张源图、取样坐标与精确RGB，并重建索引、色卡和证据图。它不调用网关、不分析用户照片，也不在每次生图中遍历69张。增加或修改样本时，先实际看图判断角色，再更新取样记录并运行复核，不能只依据颜色频率补全人工判断。
