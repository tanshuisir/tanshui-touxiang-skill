# 当前模板库与来源边界

本发布包的头像视觉参考仅为本项目重新制作、逐次修订后整理的 **70 套当前模板**，统一编号 **TS-001–TS-070**，图片位于 `assets/templates/001.png` 至 `assets/templates/070.png`。每张参考显示图为1000×1000；显示尺寸不等于模型原生输出尺寸。旧的第三方参考素材、逐图分析、作者来源和跨库编号映射不在本发布包内。

[完整模板索引](finished-reference-index.md)列出当前图片及角色信息；[机器清单](finished-reference-library.json)保存相对路径、哈希、尺寸和当前图的观察。所有角色色、线色与服饰记录均由当前模板重新整理，不从被移除的素材恢复数据。用于README的照片对照仅说明本项目的转换效果，不属于默认配色来源。

## 三种资料各自负责什么

- **用户照片**：唯一的人物事实来源，决定身份特征、神态、姿态、衣型、配饰与遮挡。
- **当前模板**：提供平面头像画法与角色配色。模板人物、衣服、动作不能复制给新照片。
- **通用规则与已确认案例**：对后续生成的质量约束。某张定稿只支持其标注的局部经验，不能推断整张图满足后来新增的每一条规则。

当前默认造型参考是 [TS-025](../assets/templates/025.png)。造型参考与配色来源可以不同，但每一版配色内部必须来自同一套当前模板。[source-colorways.json](source-colorways.json)是运行时配色入口，[source-colors.md](source-colors.md)解释随机、不重复与冻结规则。

## 独立保存与可追溯性

包内路径均为相对路径，不依赖设计师电脑上的工作目录、Figma缓存或对话附件。`source_hd_id`、`hd_reference_id` 等少量字段名仅为代码接口兼容，编号在本发布中均指当前TS模板，不代表另一套素材。新增或替换模板时，须从最终批准图重新记录像素、哈希和适用范围，再同步配色、线条、服饰与案例索引；不能只换图片保留旧取色点。

模板PNG、角色取样及定稿状态能证明文件内容和维护记录，不能证明模型每次都能复现人物或保证生成耗时。对新输出仍按[照片对照](photo-comparison-method.md)与[自检流程](quality-workflow.md)实际看图。
