# 颜如晶：人物特征转译与适度夸张

## 案例用途与来源

## 从可见特征到绘画符号

以下是对现有图像的视觉分析和可复用制作建议，不是对原作者创作过程的还原。

| 特征层 | 照片和插图提供的线索 | 可复用的概括方式 |
|---|---|---|
| 发型剪影 | 短发、齐刘海、圆拱外形 | 用一个完整发块建立外轮廓，保留刘海高度与覆盖关系；内部只留少量方向弧线 |
| 眼镜与眼睛 | 圆框显眼；插图眼白、瞳点与镜框组合突出 | 将镜框作为视觉锚点，可适度增强框形存在感；瞳点位置传达视线，避免镜框遮掉表情 |
| 脸部外形 | 面颊饱满，插图把脸概括为连续圆弧与下巴转折 | 保留圆润面部的辨识关系，省略细小皮肤纹理；不统一削成尖脸 |
| 头肩节奏 | 插图的头部倾斜明显，肩部与头部不完全平行 | 允许适度加强已有歪头，让头、颈、肩形成清楚的方向关系；颈根和衣领仍要连接合理 |
| 神态 | 插图中瞳点上移、嘴线下弯，读作疑惑或思考 | 让头倾、视线、眉眼与嘴线共同表达；可加强已有神态，不能仅凭本案例把其他人物都改成疑惑脸 |
| 服装标记 | 翻领、领结、胸前饰物在照片与插图中均醒目 | 优先保留领口与配饰类别及相对位置；花纹、文字和小装饰压缩为少量图形 |
| 配色 | 插图用青绿大面、暖深色轮廓、白面与粉色腮红组织层次 | 默认expressive艺术重配；本案例的白面、棕发和绿衣不作为新人物的固定肤发或服装色。新人物肤发衣背景按参考库或撞色方案定义，照片只锁结构神态；仅本次用户明确要求时保留自然肤发 |

关键不是每个特征都画得更大，而是在有限线条中分配注意力。本例可优先加强“眼镜与眼部神态”和“头倾”，让衣服花纹与面部纹理退后；不要同时扩大眼睛、鼻、嘴、头和所有配饰。

## 迁移到一张新照片

1. 先把照片事实写进 brief 的 `identity_features`、`expression`、`pose`，选 3–5 项辨识依据。未见结构和遮挡保持原有范围。
2. 在 `stylization` 里选择最能突出该人物的 1–2 项，说明“加强什么、保留什么、简化什么”。无需测量或逐度复现头部角度。
3. 用完整剪影建立人物，再用五官符号、视线和头肩关系强化神态。夸张需要仍能被看作同一个人、同类动作与神态；用户另有表情或姿势要求时按要求处理。
4. 从参考库或撞色方案确定肤面、头发、衣服与背景角色色，并在头发或衣服内安排至少一处清楚可见的局部二色渐变，写明起止色和方向；背景满幅不透明单一纯色，无渐变、纹理、图案或阴影，与人物大色面明显对比。这是当前制作要求，不是对本案例旧插图技法的追溯断言。
5. 若脸型或五官关系失真，收回导致失真的那项夸张；若人物特点太弱，减少无关细节并加强主特征。无需把所有夸张一并取消。

示例仅供理解，不能不看新照片就套用：

> 保留照片中饱满的面颊、齐刘海、圆镜框与五官分布。适度加强已有歪头和抬眼，让镜框中的视线与短嘴线共同表达原有神态；颈根与衣领保持连接。头发合并为完整剪影，衣服只保留翻领和领结，省略细碎花纹。

若新照片没有眼镜、领结或歪头，按新人物的实际特点选择。不要为了套用颜如晶案例添加这些标记，也不要用公众人物的外观替换用户人物。

本案例经过用户认可的是参考适用性与夸张思路，尚未验证新照片生成结果的相似度；它不是模型训练样本或已验证的原照配对数据。
