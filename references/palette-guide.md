# 配色资料入口

当前默认仅为70套TS模板的完整同源角色色。使用[source-colors.md](source-colors.md)理解选择与冻结，使用[colorway-index.md](colorway-index.md)浏览每套方案，使用[finished-palette-guide.md](finished-palette-guide.md)理解像素取样边界。所有编号均对应`assets/templates/001.png`至`070.png`。

另有用户提供的[100组四色卡](four-swatch-cards.md)，状态为`reference_only`；尚未替换默认抽色。单独要求设计新方案时，从[Coolors与Color Hunt](custom-palette-sources.md)检索一张可核验色卡，按一重色加其余浅亮色的关系映射角色，并记录具体来源和HEX。

不能从不同模板分别抽肤色、背景与衣服；不能把未标角色的四色卡第一色直接当肤色；不能把示例参数变成固定重复方案。默认流程不加载历史拼图、跨库映射或其他素材目录。
