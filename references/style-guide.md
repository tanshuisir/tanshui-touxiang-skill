# 人物头像绘制规范：100 张参考的视觉拆解

此文保留早期截图分析。新增高清成品的 [finished-style-guide.md](finished-style-guide.md) 对最终线条、暗面、配色和 1000×1000 交付规范具有更高优先级；本文的建议参数不是新的交付标准。本文数字为旧版裁切编号，不等于 HD 编号。当前制作默认expressive艺术配色，照片只锁定人物结构与神态；每张新头像必须有至少一处清楚可见的局部二色渐变。这是用户的新制作要求，不回写为对旧图逐张证明的观察结论。

依据用户于 2026-11-06 提供的 11 张作品图。图 5–10 含编号 001–100 的独立头像和对应四色色卡；图 2 为 25 格线稿；图 1 含草稿、勾线、平涂和增加色彩层次的步骤；图 3–4 为应用展示；图 11 为叠加暗色蒙层的总览。参考位置见 `reference-index.md`，原头像裁切见 `assets/portraits/NNN.png`。

下文“观察”来自可见作品；所有线宽、留白、数量和强度范围均为 **MVP 制作建议**，不是作者源文件参数或原图精密测量。没有从截图推断未展示的笔刷、图层混合模式或模型参数。

## 1. 共同语言

观察：以头肩或胸像为主，用清楚的大轮廓、近乎等粗的流畅曲线、浓缩的五官、实心眉眼、圆形腮红和大胆配色组成系列。头型、面部角度、表情、肩线、发型与服饰各不相同，形成同一种绘画语言里的不同人物。默认接近时尚编辑插图；较粗线的卡通是其中一个变体。

先锁定人物辨识度，再选择主特征进行适度夸张、简化结构，最后分配颜色。可加强发型体积、镜框形状、脸部轮廓差异、头颈倾斜和眼口表情，选其中一两个重点，其他部分保持克制。角度与比例服务于人物识别和表情可读性，无需与照片逐点重合。不把所有下颌削成同一个尖脸，不把成人画成儿童，不抹掉秃发、胡须、眼袋或圆脸等特征。详见 `yan-rujing-case.md` 的照片与插图对照。

图 3–4 的罐体高光、唱片反光、挂绳、徽章玻璃质感、场景投影和透视是展示载体，不进入默认头像。图 11 的整体变暗属于结束页蒙层，不作为头像亮度标准。标题、色卡、编号、签名及参考衣服上的商标不自动出现在新头像中。

## 2. 结构与轮廓

从照片记录脸的长宽与下颌、发际线和头发外形、眉眼位置与倾斜、眼鼻口间距、鼻唇形状、头颈倾斜、表情及可见配饰。选最能认出本人的 3–5 项作为 identity lock。发色、衣服、背景是可调层；五官关系与轮廓不能随参考人物迁移。只记录可见外观，不识别人名或推测性格。

- **脸**：以额头、颧颊、下颌、下巴的连续转折概括体积。侧脸保留额鼻唇颏节奏；正面保留轻微不对称。017、043、070 示范侧面外轮廓。
- **头发**：先画整体剪影，再用少量 C/S 弧或短折线表示分缝、卷曲与发簇。长发形成大曲线（024、028、041）；短发用有限缺口和尖簇（026、074）；后梳发用数条方向明确的弧（011、055）。不逐根描发。
- **头颈**：下颌与颈根连接明确，允许适度拉长颈部或加强原有倾斜，以突出动作节奏。以颈侧暗面、衣领说明前后，避免悬浮头、断颈和多重下巴线。
- **肩与姿势**：回眸由背肩遮挡、颈部旋转和视线共同说明（001、024、056、073）。以照片为起点，可加强已有的歪头、耸肩或头肩反向关系。保持动作可读、视角下的遮挡合理；正面改大幅回眸等涉及未见结构的重构需有额外照片或用户明确要求。姿态夸张不依赖机械复刻参考人物的角度。
- **耳**：外缘用 C 形，内部只保留耳甲或耳廓的一两处短线。配饰留可辨认形状，弱化写实金属细节。

原系列多为正方形、下缘裁肩胸、头顶留白。建议 1024×1024 中头顶留约 7%–12%，头发加面部占高度约 58%–74%，随发型和姿势调整。肩可延伸下缘，头发、耳饰、帽檐避免碰上缘。圆形头像让五官与关键配饰处于圆形安全区；长发外缘允许适当裁切。不要把头像缩成小半身照。

## 3. 线条

观察：线条平顺、转折经过概括，粗细相对稳定；细线、常规轮廓与粗线卡通共存。图 1 展示 Procreate 单线笔刷，并提示提高 StreamLine 以稳定线条；这不代表必须使用该软件。

- 主轮廓一次明确走线，避免铅笔毛边、重复描摹和抖动。圆角与尖角分别服务于头发、衣领、下颌的具体形状。
- 先让发型、脸部、衣服外形成立，内部线只保留结构与辨识信息。不为每块颜色添加重复黑边。
- 常规线宽建议从 1024 图的 5–9 px 起步，内部线约为主线的 60%–85%；粗线卡通可从 10–16 px 起步。以缩小后可读性为准，不宣称这是作者笔刷数值。
- 线色可用黑、深蓝、深绿、紫、棕或暖红，与面部色块保持明度差。一张头像尽量统一一个主线色，眉眼与主线有意协调。
- 遮挡处断线：刘海挡额头、眼镜腿接耳根、前发挡耳、衣领挡颈底。清除穿模线、双重脸线、切线粘连及填色漏边。
- 双色线描允许大片负形留白，仍要保留脸、颈、发型和衣领主次，参考 009、034、037、044、079、086。

## 4. 五官与表情

### 眉眼

眉毛多为实心短楔、短弧或斜切色块，用眉峰、粗细和倾角区分人物。眼睛常用短上眼睑与小实心眼形、水滴或椭圆形，下眼线和眼白经常省略。保留眼距、眼角走势、开合与视线。不默认大虹膜、动漫高光或同款睫毛；照片与参考支持时才用少量短线强调睫毛（064）。

闭眼、笑眼、低垂眼、仰视与侧目通过眼睑和眉眼关系表现，不只给同一张脸换嘴角。闭眼见 007、032、071；点眼与短眉见 091–095。

强调表情时联动头倾、眉眼开合、瞳点方向和嘴线。例如 087 通过圆镜框中的眼白与上移瞳点、倾斜头部、向下弯的短嘴线强化疑惑感。可为表达清晰而适度扩大眼部符号，不把所有人物改成同款大眼；这描述插图表现，不证明其原照片也有完全相同的动作。

### 鼻与嘴

鼻子常用短鼻梁折线或弯钩，把鼻尖、鼻底、鼻翼压缩成一两个提示。正面避免完整描两侧鼻梁；侧面鼻形已由外轮廓说明，内部补线更少。保留鼻梁长短、鼻尖方向及鼻口距离，不用同一个钩鼻符号替换所有人。

闭口多为有角度的短线，必要时加极短下唇提示。微笑通过嘴角、眼睑、面颊共同完成；张嘴可用深色负形加少量牙齿留白（007），不逐颗画牙。口红只在照片或用户要求支持时出现。胡须/胡茬用有限色块或短线保留；不要把嘴下短线都当成胡须（023、030、035、065）。

### 圆形腮红

圆形或略椭圆的平涂腮红是多数彩色头像的共同特征，位于眼下、鼻翼外侧，可随色板变成粉、珊瑚、橘、紫、青绿或黄。它是一块图形，通常不是大面积空气喷枪晕染。

建议直径约为可见脸宽的 12%–20%。侧脸只出现可见面颊或缩窄远侧那块，依透视和遮挡决定。腮红不盖住眼、鼻线、镜框或关键痣。纯线描和强双色模式可减弱或省略腮红，不为统一风格强加圆点。

### 眼镜、遮挡与手

镜框形状、宽度和鼻梁位置是辨识要素。镜片可浅透色，保留后方眉眼并正确连接镜腿（018、024、031、047、078、087）。墨镜、口罩与手机遮住的部分保持遮挡，不擅自补画。013 的口罩与 045/077 的手机只提供遮挡画法，不给其他照片人物添道具。手用连续外形与少量指缝概括，保持实际可见的手指数量、关节方向及接触位置，不额外生成手。

## 5. 色块、层次与服饰

默认平整、边缘清楚的大色块。面部基色只辅以有限的颈侧、下颌下方或脸侧暗面；明暗依附结构，不给整脸刷照片式连续渐变。浅面颊与深眉眼清楚分离。默认expressive：肤面、头发、服装与背景按参考库或撞色方案重配，可用黄、白、粉紫、青绿等艺术色，不受照片原色约束；照片只锁定脸型、五官、发型剪影、神态和可见衣型配饰。只有本次用户明确要求保留真实肤发时才用natural，仍保留局部渐变。

四色色卡是主色提纲，不表示画面只有四个 RGB。眉眼、腮红、暗面、高光、渐变与抗锯齿都会增加颜色，不为凑四色删掉人物信息。详见 `palette-guide.md`。

**渐变**：观察到001、005、007、020、028、039、041、064、090在头发、衣服或背景内部作单方向二色渐变。当前新头像每张必须有至少一处、通常1–2处可见连续二色渐变，写明区域、起止色与方向；约束在封闭色块内并保持清楚外轮廓，不把脸画成油亮3D。硬边暗面、两块色、短亮线和抗锯齿不能替代渐变。

**衣服**：先保留圆领/V领、高领、衬衫领、翻领、帽衫、背带的类别特征，少量线说明肩线、领口、袖缝和必要褶皱。通常一两个主色；项链为曲线加吊坠，扣子为点或小圆。照片中无关商标文字可简化为纯色，用户要求保留时除外。

**纹理**：针织平行细线（031、032、063）、格纹交叉线（042、075）、重复斜线（059）、圆点/网点（065、073）、顺肩面排线（076）。在衣服内部裁切，方向顺体积；缩小成噪声时减密或省略。不把纹理铺到脸、背景及所有衣服。图 1 小图中的网纹可能含截图采样影响，不据此指定必需笔刷。

**背景**：单块纯色或简单二色渐变，利用明度、冷暖或饱和度差分离发型。白色/浅色负形同样有效（009、037、040、079）。新头像默认不包含展示页的大底色、版式、标题、编号或样机。

## 6. 可选模式：确定一个主模式

| 模式 | 参考 | 核心表现 |
|---|---|---|
| flat 平涂基础 | 002、011、022、024、047、072、098 | 常规轮廓、精简眉眼、圆腮红、大色块，并保留至少一处局部渐变 |
| gradient 局部渐变 | 005、020、028、041、064、090 | 平涂基础上，一两个封闭区域内渐变 |
| texture 服装纹理 | 031、042、059、063、065、073、075、076 | 仅衣服局部细线、格纹、网点 |
| bold 较粗轮廓 | 030、043、060、077 | 少结构线、有力外轮廓，保留照片年龄和头型 |
| cartoon 粗线卡通 | 015、087、091–095 | 紧凑简化五官、少量弧线、粗主线、圆腮红 |
| duotone 双色/同色系 | 009、033–038、044、054、078、079、081、084、086、100 | 主线加少量色块、负形留白，或同类色组织 |
| glitch 窄偏色边 | 040 | 黑白平面骨架，局部青/粉微小错位边，不使脸重影模糊 |

模式标签为本 Skill 的检索归纳。个别参考混合手法，默认只选一个主模式，所有新头像模式都叠加必需的局部渐变，其余辅助手法按需使用，不把所有效果叠加。参考人物的脸、发型、性别表现、年龄、配饰不随模式迁移。

## 7. 执行顺序

图 1 明示选参考打草稿 → 勾线 → 上色 → 添加色彩层次，可复用为：

1. 结构：头部角度、发型剪影、面部中心线、五官关系、肩线。
2. 勾线：先外形，再眉眼鼻口、耳与配饰，清理遮挡与多余线。
3. 平涂：按实际遮挡组织背景、后发、身体、颈、脸/耳、前发、道具。此分层是制作建议，不是作者工程图层清单。
4. 层次：有限暗面和圆腮红，明确眼镜遮挡后补镜片透色，每张安排至少一处清楚可见的局部二色渐变；衣服纹理按需选择。
5. 快速交付：默认一次调用，整理尺寸后直接展示，不自动制作128缩略图或重画。只有用户明确要求详细自检时读取 `quality-workflow.md`，再核对人物结构、艺术配色与必需渐变。

对 AI 图片编辑，此顺序组织在一条明确提示词中，不要求四次付费调用，不输出草稿拼版。

## 8. 偏离与修正

| 反馈/偏离 | 修正方向 |
|---|---|
| 不像本人 | 重锁脸型、发际线、眼距、鼻口关系、表情，减少通用模板脸；只降低造成失真的夸张 |
| 太像描照片、人物特点弱 | 从已观察到的特征中选 1–2 项加强；用头倾、视线和嘴线协同表达，减少无关细节 |
| 太像照片/3D | 减少皮肤连续阴影、毛孔、镜面高光和密集发丝，加强轮廓与平涂 |
| 太动漫/幼态 | 缩小眼睛、移除虹膜高光，恢复照片年龄、下颌和五官间距 |
| 只有颜色像 | 回到线条、五官符号、颈肩构图与圆腮红 |
| 线太脏 | 删重复线、短碎发线和全局噪声，留主轮廓与关键结构 |
| 腮红过大 | 缩小圆块、按面颊透视放置、降饱和，不改嘴眼位置 |
| 配色刺眼 | 减少高饱和面积，用深线和合适肤色固定面部，强调色只用局部 |
| 借用了参考道具/发型 | 重申照片只决定人物结构神态和衣型配饰，风格图提供线与艺术配色手法 |
| 多人头像不成系列 | 统一主模式、线条强度、腮红和构图节奏，保留每人的头型五官 |

当前尚无用户人物照片的生成验收样张。上述内容已做参考图视觉核对；人物相似度与模型风格执行效果仍需实际照片编辑后的用户反馈验证。
