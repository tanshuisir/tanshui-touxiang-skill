# 真实照片与插图的对照学习

用于用户要求找真人参考、补充人物案例，或希望解释照片如何被概括成当前画风时。先读本次的 `public-photo-catalog.json`；其中按姓名检索到的照片与已确认的插图配对是两种资料。

## 人名、编号与照片来源

只有作品上的人名、作者说明或用户确认的编号对应，才能建立插图人物字段。未标注的头像保留 HD 编号。外观相似、图片搜索排序、同一网页出现两个名字，都不足以证明人物对应。

两个库的编号不同：高清 `HD-001–070`（缺 051），旧拼版 `OLD-001–100`。`artwork-crosswalk.json` 保存 69 张相同插图在两套库中的对应；这是完整图形的版本匹配，不是人脸身份判断。已带人名的颜如晶案例为 OLD-087，没有这批高清对应图。

人名可能涉及别名、艺名、角色名或误写。保留用户原文，规范名与文字依据另存；“都教授/都敏俊”类角色与饰演者分别记录。存在歧义的称呼先挂起，不用最热门搜索结果补齐。

每张照片保留原网页、图片地址、可读的标题或图注、查看日期与本地文件。网页明确归属且实际看过图后，才能把照片列为可用造型参考。仅图片搜索缩略图、失效链接、登录页或验证页，保留为检索线索，不列为已核验照片。

目录另保留一张有姓名说明、已查看画面但详情原页受阻的 Yamy 人物知识卡，标为 `search_card_reference`，单独提示来源限制。它只支持造型观察，不计为原文核验或插图人物配对依据。

都敏俊条目中的一张剧照只取得同时提及两个角色的原文上下文，标为 `contextual_candidate`，人物归属仍待补证。可观察画面中的高衣领与遮挡，不能把这张候选当作已确认的单一人物资料。

## 如何选择有用的照片

为具体插图寻找最贴合的照片时，先确认该插图人物有文字依据，再在该人物的公开照片中选择。按用户明确提供的姓名建立照片资料可以先进行，但不据此填入插图编号。优先找与作品时期接近、头肩清楚、少遮挡的照片；如用户另指定新造型，则以新造型为准。

| 比较层 | 先看什么 | 如何处理差异 |
|---|---|---|
| 外形与比例 | 头发完整剪影、脸与下颌转折、五官相对分布 | 同时期照片的差异先考虑拍摄角度；不能从不匹配的参考推导作者“削脸”“放大眼睛” |
| 动作 | 正侧面类别、抬低头、左右倾斜、头与肩的反向关系 | 同类动作即可；已有歪头可加强，颈根和肩线要重新连接 |
| 神态 | 视线、眉的起落、眼睑开合、嘴线方向 | 有疑惑、笑或抿嘴的近似参考比只有相同衣色更有用；不凭人物姓名套默认神态 |
| 造型标记 | 发型阶段、刘海分区、眼镜、耳饰、衣领与手部动作 | 同类标记优先；照片不存在的配饰不因参考画中有而添加 |
| 配色与光影 | 衣服与背景分离、头肩遮挡和颜色组织 | 单图与四图均用expressive完整同源方案，照片色不锁定；natural与同源规则冲突，停止说明。光影按输出姿态重建，不能用颜色接近证明原照关系 |

选一张主照片负责五官、姿态和遮挡。辅助照片只解决主照片看不清的已有结构；不同年龄、发型阶段、表情或左右朝向不能无说明地拼合。头肩照片不足时可保留全身原图并做头肩查看裁切，裁切不等于取得更高清的原图。

每个候选只写“可比之处 / 明显差异 / 适用范围”，不要输出没有标注验证集支持的相似度百分比。“近似参考”不能改写成“作者创作原照”；即使造型很近，也只能在确有作者出处时升级为原照配对。

## 将对照变成绘画决定

把观察按以下顺序写成简短记录，随后转入已有 brief 字段，不需要把人物名字塞进生图提示词。快速流程只保留简短特征观察，不必填写逐项计划或启动自检；只有用户明确要求review时才把每项主特征填入 `identity_plan`，按 `quality-workflow.md` 记录照片证据与本次画法：

1. **保留关系** → `identity_features`：选择 3–5 项照片实际可见的比例、剪影和造型锚点。优先写“眼距与脸宽的关系”“下颌的圆弧与转折”，不要只写“像某明星”。
2. **主导动作与神态** → `pose` / `expression`：分别描述头轴、肩轴、视线和嘴线，保留不对称。身体可转向一边、眼睛看另一边，不能都压成同一方向。
3. **选择性加强** → `stylization`：只选 1–2 项，例如已有的发型体积、镜框存在感或头倾。保持原有关系的方向，不同时扩大所有五官；加强一处时，让次要发丝、衣褶和纹理退后。
4. **概括与删减** → `stylization` / `clothing`：发丝合并成发块；眉眼变实心符号但保留间距与眼睑方向；鼻口用短线保留位置和方向；衣领、眼镜和遮挡边缘比零碎花纹优先。
5. **重建层次** → `shadow_plan`：先建立头颈连接，再画下颌落在颈部的影；发下、耳后与衣领处只补必要接触暗部。头倾改变后，承影面跟着改变。腮红服务色彩节奏，不能代替结构暗面。
6. **迁移颜色角色** → `color_roles`：默认expressive，从高清参考或撞色方案重新组织背景—主线—肤面—暗面—头发—衣服—强调色，不受照片肤发和衣色约束。照片只锁定人物结构、神态、衣型与配饰形状；自然肤发仅在本次用户明确要求时保留。每张新头像必须在头发或衣服内安排至少一处清楚可见的局部二色渐变，标明起止色与方向，不能用两块硬边色冒充。背景满幅不透明单一纯色，无渐变、纹理、图案或阴影，与人物大色面明显对比。这是当前制作要求；不要因照片与旧插图发色不同就推断作者用了固定换色公式。

这些是对照观察得到的制作建议。没有真实原照配对时，只能说明“这项照片信息可以怎样概括”，不能声称还原作者的逐步创作过程。

## 本轮照片带来的具体绘制判断

以下是照片造型研究，照片地址、查看记录和本地文件见 `public-photo-catalog.json`。除已有颜如晶案例外，不在此指定任何高清插图人物编号。

| 照片中的触发条件 | 可以复用的绘画决定 | 需要克制的地方 |
|---|---|---|
| 蔡徐坤参考的白衬衫、小领结与宽黑翻领 | 先安排白色领口负形，再以领结和外套两个深色形锁住胸前结构 | 不让衣服上的摄影绒面反光变成脸部亮纹；没有领结的新照片不添加 |
| Yamy 人物卡参考的齐下颌短发、抬下巴、半开眼睑与单侧耳饰 | 用发尾高度及偏斜头轴建立剪影；保留眼睑开合，耳饰压成清楚链形 | 不统一放大双眼；人物卡来源尚弱于可读原文，不能作创作原照证据 |
| 迪丽热巴参考的侧转、大波浪与单侧长耳饰 | 将卷发组织为少数连续主弧线，保住脸旁负形与耳饰位置 | 头发渐变只在发块内部，不能抹平颈部遮挡或卷发外缘 |
| 毛毛姐参考含相邻两帧的橘红假发和不同张嘴/闭眼表情 | 先选一帧，锁定假发剪影，再取该帧的眼睑与嘴形组合 | 不能把一帧的闭眼和另一帧的嘴形无说明地拼成“原有表情”；视频字幕不进入头像 |
| 官方 D.O. 资料照的白色立领与红色背景侧影 | 外套可合成深块，立领保留为小负形；头颈结构另画 | 红色墙面投影属于摄影场景，不自动变成头像背景悬浮影；低分辨率参考不放大冒充高清 |
| 都敏俊条目的角色造型候选中，大衣高翻领遮住颈部 | 以大衣领口与下颌的前后关系建立体积，只画实际露出的颈面 | 不套用裸露长颈模板或机械加一整条颈影；单图人物归属待补证，角色与演员本名分开 |
| XIUMIN 候选参考的冷蓝侧光与小圈耳饰 | 明暗可以压为一个受脸转向约束的硬边暗形；小圈保留一个清楚孔洞 | 冷光颜色是摄影照明，不推定为实际肤色；“秀敏”的姓名解释仍待确认 |
| 章子怡参考的托腮动作 | 先确定手掌承托与脸颊接触的边界，再概括手指和脸颊；在真正接触处保留短暗部 | 不把手移到脸外形成悬空动作；接触暗部不能画成沿脸一圈的粗轮廓 |
| 朱一龙参考的一只眼闭合、另一只眼睁开 | 分别记录两侧眼睑与眉线，用一短弧和一小实心形保留表情的不对称 | 不为了对称而把双眼都画成睁开或闭合；避免额外放大另一只眼 |
| 陈伟霆参考为黑白照片、华晨宇参考受蓝色舞台光影响 | 可研究剪影、动作、明暗层级与遮挡；默认按参考库或撞色方案重配，只有本次明确要求自然肤发时另取有依据的彩色参考 | 不从黑白图猜具体肤发色，不把蓝色灯光当作实际发色或肤色 |

相近造型不能证明人物身份相同。上述规则的作用是让下一次看一张新照片时，能根据实际触发条件选择表达方法，而不是把某个姓名对应的发型、肤色或配饰当作固定模板。

## 案例成熟度

`photo_only` 表示已取得有姓名出处的照片，但没有插图人物编号依据；它可用于观察造型，不能作为人物配对案例。`comparison_reference` 表示人物对应有依据、照片适合比较，但原照关系未证实。`author_source_pair` 只用于作者明确提供原照的情况。

目前可完整使用的是用户认可的 [颜如晶近似参考](yan-rujing-case.md)。新照片库中的其他人物，只有在取得编号对应文字后才新增比较案例。本地参考收录不等于模型训练、权重更新或已验证的新照片生成效果。
