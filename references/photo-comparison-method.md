# 从照片到头像的对照方法

用户照片是人物事实来源，TS模板是画法和角色色来源。二者分别保存，不能把先前头像当作原照片重新塑形，也不能从姓名或相似外观推测人物身份。普通`--photo`路线由生图模型读取照片，主模型仍须在生成后实际看图，不能把保留要求当成已观察证据。

## 先看关系

| 比较层 | 照片观察 | 插图处理 |
|---|---|---|
| 外形 | 脸宽、下颌转折、头发体积与长短 | 保留剪影与相对比例，适度加强1–2项真实特征 |
| 五官 | 眼距、眉眼关系、眼睑方向、嘴宽和开口 | 符号化但不缩掉辨识性，保留左右差异 |
| 动作 | 头轴、肩轴、抬低头、视线、手臂动作 | 保留关系，完整安排肩肘腕和画框补全 |
| 衣饰 | 领型、衣层、肩带、首饰、道具和实际遮挡 | 独立分区，遮挡后重现的部件连续 |
| 光影 | 头颈连接、下颌承影、接触关系 | 重建少量硬边结构影，不照搬摄影柔光 |
| 颜色 | 可记录但不默认锁定照片颜色 | 每版使用一套当前TS完整角色色 |

照片是大头或半身截断时，适当拉远完成胸像，不把被画框切掉的肩、臂照搬为插图截断；真实被衣服、头发或前景遮住的部分仍保持隐藏。可以从辅助照片理解已有衣物结构，但不同人物、年龄、发型阶段、表情或朝向不能无说明拼合。

## 观察转成决定

手写brief时选3–5个实际可见锚点，至少含脸型/下颌或五官关系，不只写发色衣色或“像某明星”。每个锚点写保留关系，必要时挑1–2项适度加强；其余删减为大面与短线。发型写剪影、分缝和遮挡，不罗列每缕发丝。眼睛写方向、开合和间距，不把眼白、虹膜或反光当必须复刻特征。

衣服先辨外套、内搭和领袖，手臂先建肩肘腕。下颌影跟随头颈方向；腮红不能代替结构影。道具先认材料与接触，再从本套角色色分配，不用颗粒堆质感。

## 实际核对

完成后对照原照、实际成品及独立风格图，优先看身份、神态、头肩、构图和贴底，再看眼嘴比例、脸缘、颈影、轻腮红、衣层、手臂、项链与道具。观察应具体，例如“照片下颌宽圆，成品削成尖角”，不能用“相似度不错”替代。

未看见或无法确认的结构记为不确定，不猜为通过；不输出无验证支持的相似度百分比。像素统计不能判断人体、表情或衣物连接。详细记录仅在用户明确要求时进入[review流程](quality-workflow.md)。

## 定稿与新案例

先展示预览，用户确认后才另行生成高清或替换外部设计稿。用户要求基于原照片重绘时，以原照片恢复结构，不能在错误旧头像上持续叠补。确认修订只形成有适用范围的规则，见[案例](confirmed-corrections.md)；不把某个人的唇型、眼形、衣服或局部坐标固化为全部新人物默认。
