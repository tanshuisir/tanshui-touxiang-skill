# 高清成品索引：69 张标准头像

HD 编号保留原文件名；缺少 HD-051。与旧版 001–100 裁切编号独立。以下分类是本 Skill 的视觉分析。

全部单图：`../assets/finished/NNN.png`，均为 1000×1000；总览为同目录 `contact-1.jpg` 至 `contact-4.jpg`。

按需选择一个主模式；观察单图后，可借用人物区域的局部渐变、纹理或亮线。不要把人物、服装或道具随画法一起复制。下表保留历史背景技法观察；新头像只用满幅不透明单一纯色背景，无渐变、纹理、图案或阴影，必需渐变仅限头发或衣服。
